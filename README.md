# Autumn (Not the season)
Autumn in a nutshell it's a Textual WM. It's not a fork of twin (another Textual WM), but i made this because twin is pretty outdated.
It's released under the CC0 1.0 (Creative Commons 1.0 Universal) license, meaning idc if someone uses my code in any way.
Autumn has a rolling-release model. There aren't snapshots.
